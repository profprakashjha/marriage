# Shalu & Prakash Wedding Website

A responsive, static wedding invitation website prepared for GitHub Pages.

## Publish it on GitHub

1. Download and unzip `Shalu_Prakash_Wedding_Website.zip`.
2. Create a new repository on GitHub, for example `shalu-prakash-wedding`.
3. Upload **the contents of this folder** (`index.html`, `style.css`, `script.js`, and `assets/`) to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site; the URL will appear in Settings → Pages.

## Included features

- Responsive design for phones and desktops
- Invitation artwork
- Wedding venue and pre-wedding event schedules
- Clickable Google Maps links
- Tap-to-call RSVP number and WhatsApp message link

## Before publishing

Review the names, dates, times, spelling, and phone number. Google Maps links are the two links supplied for the invitation.
